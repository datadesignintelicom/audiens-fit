# FAQ — Audiens Fit

**Preciso de internet?** Só na preparação do pendrive (o instalador baixa
Ollama, Python e modelos para dentro dele). No uso, tudo roda offline e a
máquina não precisa de nada instalado.

**Meus dados saem da máquina?** Não. Planilha, análise e perguntas são
processadas localmente. Nada é enviado a nenhum servidor.

**Por que o antivírus reclama do .bat?** Scripts .bat são um formato que
malwares também usam, então SmartScreen/antivírus alertam por precaução.
Os deste projeto são texto aberto — leia antes de executar.

**Posso mudar como a IA interpreta?** Sim: edite prompts/prompts.json
(preserve os {placeholders}). É a metodologia inteira, em texto.

**Qual a diferença para o Audiens completo?** O completo (interno da
Data Design) coleta direto das plataformas, usa modelos maiores e camadas
extras de análise. O Fit é a edição portátil, aberta e planilha-first.

**A análise trava minha máquina?** Ocupa a maior parte da RAM enquanto roda.
Feche o que for pesado; em 8 GB, evite usar o navegador durante a análise.

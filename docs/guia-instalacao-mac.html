Instalar o Audiens Fit num pendrive

O processo tem uma parte técnica — Terminal, um aviso de segurança do Mac — mas você só passa por ela uma vez. Depois disso, usar o Fit é clicar num ícone. Este guia mostra as duas partes separadas.

Mac Apple Silicon ou Intel Pendrive exFAT, 16 GB livres Internet só para preparar Tempo ~10-20 min (rede boa)
1

Preparar o pendrive

Feito uma única vez, na máquina que tem internet. O pendrive pronto funciona depois em qualquer Mac, sem internet.

1

Baixe e descompacte

Na página do projeto no GitHub, botão verde Code → Download ZIP. Descompacte — vira uma pasta chamada algo como audiens-fit-main.

2

Plugue o pendrive

Formatado em exFAT (o padrão de fábrica da maioria) — não precisa fazer nada especial nele antes.

3

Abra o Terminal

Cmd + Espaço, digite terminal, Enter. É um aplicativo do próprio Mac.

4

Entre na pasta e rode o instalador

Truque para nunca errar o caminho: digite cd e um espaço, depois arraste a pasta descompactada para dentro da janela do Terminal — o caminho se preenche sozinho. Enter. Repita o truque para o pendrive, arrastando o ícone dele.

terminal — zsh
mac ~ % cd audiens-fit-main
mac audiens-fit-main % ./instalar-mac.command AUDIENSFIT
══ Audiens Fit: instalando em /Volumes/AUDIENSFIT ══
→ Copiando o aplicativo…
5

O Mac vai bloquear na primeira vez — é esperado

Qualquer script baixado da internet recebe esse aviso, não é específico do Fit. Duas telas para passar por isso.

Aviso de segurança

"instalar-mac.command" não pôde ser aberto porque a Apple não pode verificar se contém malware.

Este software precisa ser atualizado. Entre em contato com o desenvolvedor para mais informações.

6

Libere em Ajustes do Sistema

Ajustes do Sistema → Privacidade e Segurança → role até o fim. Aparece um aviso recente com o botão Abrir Mesmo Assim. Clique, confirme com sua senha ou Touch ID.

"instalar-mac.command" foi bloqueado para proteger o seu Mac.

Volte ao Terminal e rode o mesmo comando do passo 4 de novo — dessa vez ele passa direto.

7

Acompanhe os downloads

O instalador baixa sozinho o Python, o Ollama e o modelo de IA (~2,5 GB) direto para o pendrive. Barra de progresso no Terminal — o tempo depende só da sua internet.

terminal — zsh
→ Baixando Python relocável (arm64)…
→ Baixando Ollama standalone…
→ Baixando o modelo do perfil normal (qwen3:4b-instruct, ~2.5 GB)…
74%
Baixar também o modelo turbo qwen3:8b (5.2 GB, máquinas de 16 GB+)? [s/N]

O turbo é opcional — só compensa em Mac com 16 GB de RAM ou mais. Pode responder N e adicionar depois, com calma.

8

Pronto

O Terminal avisa Instalação concluída e pergunta se quer abrir agora. Essa foi a parte técnica — não se repete.

terminal — zsh
══ Instalação concluída. ══
Para usar: abra o aplicativo 'Audiens Fit' (ícone Af) na raiz do pendrive.
Abrir o Audiens Fit agora? [s/N]
2

Duplo clique em "Audiens Fit"

Carregando o modelo pela primeira vez…

Primeira carga do modelo, do pendrive: 1 a 3 minutos. Nas vezes seguintes é mais rápido.

3

Analise sua planilha

XLSX ou CSV, coluna de comentários detectada sozinha. Tudo roda ali, no seu Mac — nada sobe para a internet.

4

Ao terminar, "Encerrar Audiens"

Libera a RAM que o modelo estava usando. Só fechar a aba do navegador não faz isso sozinho.

?

Se algo sair diferente

Uso: instalar-mac.command…

Apareceu porque o Terminal não sabia qual pendrive usar. Se você tiver mais de um disco externo plugado, o instalador lista os disponíveis numerados — digite o número do seu. Com só um pendrive plugado, normalmente ele nem pergunta.

ERRO: Python do pendrive não encontrado

Sinal de que a instalação não terminou (foi interrompida, ou a internet caiu no meio). Repita o passo 4 — o instalador é seguro para rodar de novo, ele pula o que já baixou e completa só o que falta.

Nada abre ao clicar duas vezes

Confirme que o pendrive foi ejetado corretamente da última vez (não retirado direto) e que está formatado em exFAT. Em caso de dúvida, uma reinstalação (passo 4) resolve sem apagar nada que já funciona.

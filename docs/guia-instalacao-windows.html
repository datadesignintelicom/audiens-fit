Instalar o AudiensBR Fit no Windows

A instalação foi testada numa máquina virtual Windows e ainda não num computador comum. As telas são ilustrativas. Encontrou algo diferente? Escreva pra audiensbrasil@proton.me.

Windows 10 (1803 ou mais novo) ou 11 Espaço 16 GB livres Internet só para preparar
1

Instalar

Feito uma única vez, com internet. Não é preciso instalar Python nem Ollama: o instalador baixa os dois para o destino.

1

Baixe e descompacte o projeto

Na página do GitHub, botão verde Code → Download ZIP. Clique direito no ZIP baixado → Extrair Tudo.

2

Escolha onde instalar

De preferência um pendrive ou disco externo rápido, em exFAT. Plugue e veja a letra dele em "Este Computador", por exemplo E:. Também pode ser uma pasta do computador.

3

Abra o instalador

Na pasta descompactada, dê duplo clique em instalar-windows.bat.

5

Informe o destino

Digite a letra do disco, como E:\, ou o caminho de uma pasta. Só Enter instala na pasta indicada entre colchetes.

6

Acompanhe os downloads

O instalador baixa o Python, o Ollama (cerca de 1,7 GB) e o modelo de IA (cerca de 2,5 GB). O tempo depende da sua internet e da velocidade do disco. O modelo turbo é opcional, para máquinas com 16 GB de RAM ou mais; sem ele, o Fit usa o modelo normal.

2

Usar no dia a dia

Sem internet, neste computador ou em outro com Windows, levando o disco. Não é preciso instalar nada nele.

1

Duplo clique em AudiensBR Fit.bat.

Numa máquina diferente da que preparou, o SmartScreen do passo 4 pode aparecer de novo.

2

O navegador abre sozinho

Em localhost:5001. A janela preta atrás mostra o andamento — não feche, é o motor rodando.

3

Para encerrar

Dê duplo clique em Encerrar AudiensBR.bat. Ele fecha só o Fit, libera a RAM e permite ejetar o disco.

?

Se algo sair diferente

ERRO: download do Python (ou do Ollama, ou do modelo) falhou

Confira a internet e abra o instalador de novo com o mesmo destino: ele pula o que já está pronto.

ERRO: a porta 11435 ja esta em uso

O AudiensBR Fit está aberto. Abra Encerrar AudiensBR.bat e rode o instalador de novo.

ERRO: este Windows nao tem o tar

A instalação precisa do Windows 10 versão 1803 ou mais novo.

Antivírus alerta sobre o .bat

Scripts .bat são texto puro — clique direito → Editar para ler exatamente o que fazem antes de rodar, se quiser conferir.

Instalar o Audiens Fit no Windows

Este caminho ainda não foi testado numa máquina Windows real — o guia mostra exatamente o que o instalador faz, para quem topar ser o primeiro teste. Encontrou algo diferente? Escreva pra audiensbrasil@proton.me.

Windows 10 ou 11 Pendrive exFAT, 16 GB livres Internet para preparar
⚠️

Duas diferenças importantes em relação ao Mac

  • O pendrive ainda não é independente da máquina. O instalador cria um ambiente Python (venv) que aponta para a instalação já existente no computador — não uma cópia completa. Toda máquina que for USAR o pendrive precisa ter Python e Ollama instalados nela, não só a que preparou.
  • Ainda não existe um "Encerrar Audiens" para Windows — fechar a janela do terminal basta, mas não há um clique dedicado para liberar a RAM.
0

Antes de começar

Só na máquina que vai preparar o pendrive. Pule se ela já tiver os dois instalados.

A

Instale o Python

Baixe em python.org/downloads. Na primeira tela do instalador, marque "Add python.exe to PATH" antes de clicar em Install.

B

Instale o Ollama

Baixe em ollama.com/download e rode o instalador — não pede nenhuma opção especial.

1

Preparar o pendrive

1

Baixe e descompacte o projeto

Na página do GitHub, botão verde Code → Download ZIP. Clique direito no ZIP baixado → Extrair Tudo.

2

Plugue o pendrive e note a letra dele

Abra "Este Computador" — o pendrive aparece como uma letra, por exemplo E:. Formatado em exFAT.

3

Abra o Prompt de Comando na pasta certa

Dentro da pasta descompactada, segure Shift e clique com o botão direito num espaço vazio → Abrir janela do PowerShell aqui.

4

Rode o instalador com a letra do pendrive

Troque E:\ pela letra real do seu pendrive.

5

Acompanhe o download do modelo

Numa máquina diferente da que preparou, o SmartScreen do passo 5 pode aparecer de novo — ainda não existe, no Windows, o "já liberado" que o Mac tem.

2

O navegador abre sozinho

Em localhost:5001. A janela preta atrás mostra o andamento — não feche, é o motor rodando.

3

Para encerrar

Feche a janela do Prompt de Comando (ou Ctrl+C dentro dela). Ainda não existe um atalho dedicado para liberar a RAM como no Mac.

?

Se algo sair diferente

ERRO: Python nao encontrado

O passo 0-A não foi feito, ou foi feito sem marcar "Add python.exe to PATH". Reinstale o Python marcando essa opção e rode o instalador de novo.

AVISO: Ollama nao instalado

O passo 0-B não foi feito. Instale o Ollama e rode instalar-windows.bat E:\ de novo — ele pula o que já está pronto.

Antivírus alerta sobre o .bat

Scripts .bat são texto puro — clique direito → Editar para ler exatamente o que fazem antes de rodar, se quiser conferir.
